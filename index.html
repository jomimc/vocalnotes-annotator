Syllable Annotator

Open a folder containing one audio file and, optionally, its annotations (*notes.csv, *pitches.csv, *syllables.csv, *.txt).

Files are read in your browser only — nothing is uploaded. Your annotations are saved into an annotations/ folder inside the track folder (Chrome / Edge; other browsers download them instead).

This browser cannot write into folders: saved files will go to Downloads. Use Chrome or Edge to save directly into the track folder.
